# KinetiQ 專案摘要

更新日期：2026-08-01

## 產品目標

建立個人化智慧肌貼導引網站，將使用者資料、不適關節、症狀、姿態影像與身體比例整合成肌貼參數、照片模擬與 AR 貼附引導。

## 目標使用者

- 有運動後關節周圍痠痛、緊繃或輕微不適，想正確使用肌貼的一般使用者。
- 健身、跑步及球類運動族群。
- 可將工具用於衛教或操作輔助的運動防護與復健相關人員。

## 目前產品流程

1. 輸入性別、年齡、身高、體重與體型，計算 BMI。
2. 選擇左／右肘、腕、膝或踝，也可點人體模型關節。
3. 回答不適方向、狀態及扭傷／拉傷／撞擊／過度使用等原因。
4. 開啟鏡頭進行指定姿態校正。
5. 產生肌貼類型、長度、方向、起點與拉伸比例。
6. 拍攝患部照片，在網頁上調整肌貼位置、長度與 -90° 至 90° 角度。
7. 以相機、人體關節辨識、比例縮放及半透明肌貼進行逐條 AR 引導。

## 重要產品決策

- 不適區域改為「不適關節」。
- 不提供肩膀與髖關節選項；目前僅支援肘、腕、膝與踝的左右側。
- 第一頁不進行體型相機掃描，改用身高、體重、體型與 BMI。
- 膝部方案使用「雙 I 型交叉包覆」，不可誤標為 Y 型。
- I 型是未分叉直條；Y 型是一端保留共同錨點、另一端縱向分成兩尾。
- AR 是操作定位原型，不是傷勢診斷或醫療器材。

## 成功標準

- 手機可開啟相機並允許前後鏡頭切換。
- 使用者能完成照片模擬與逐段 AR 引導。
- 人體節點模型失敗時仍可手動點擊關節校準。
- 桌電與筆電可由同一私人 GitHub 儲存庫同步。

## 不做事項

- 不宣稱診斷、治療或取代醫療專業判斷。
- 目前不保存使用者健康或拍攝資料至後端。
- 未經臨床驗證前，不宣稱貼附參數具有醫療精準度。
