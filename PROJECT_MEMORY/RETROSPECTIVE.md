# KinetiQ 專案復盤

更新日期：2026-08-01

## 有效做法

- 先建立完整可操作流程，再逐步修正醫療術語、鏡頭與肌貼視覺。
- 使用照片模擬銜接參數生成與 AR，讓使用者在實際貼附前確認位置。
- AR 模型搭配手動校準備援，比完全依賴即時 AI 更適合網頁原型。
- 同時保留 GitHub 與 Sites remote，分開處理跨裝置開發與公開部署。

## 需要改善

- `README.md` 仍是 vinext starter 說明，後續應改為 KinetiQ 專案首頁。
- 功能步驟目前仍有順序限制；使用者曾提出不要限制功能順序，尚未正式落實。
- MediaPipe 從外部 CDN 載入，離線或受限網路會失敗。
- 尚未進行正式的多款手機、光線、距離與遮擋測試。
- 肌貼路徑與比例目前是互動原型，尚未經臨床或人體量測驗證。

## 下一階段建議

1. 解除側邊功能順序限制，同時保留建議流程提示。
2. 建立每個關節對應的專用貼法與安全排除條件。
3. 加入鏡頭構圖品質、關節可見度與距離提示。
4. 與物理治療師或運動防護員共同驗證貼附方案。
5. 建立手機實機測試清單與隱私政策。
